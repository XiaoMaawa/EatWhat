## 1 通用规范

### 1.1 协议与编码

| 项 | 规范 |
| --- | --- |
| 协议 | HTTP/1.1（生产环境强制 HTTPS） |
| 数据格式 | JSON，`Content-Type: application/json; charset=utf-8` |
| 字符编码 | UTF-8 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`（东八区） |
| 金额格式 | 字符串形式的十进制数，如 `"29.90"`，避免浮点误差 |
| 分页参数 | `page`（从 1 开始）、`size`（默认 10，最大 100） |

### 1.2 URL 命名规则

| 规则 | 正例 | 反例 |
| --- | --- | --- |
| 资源名用复数名词 | `/dishes` | `/getDish` |
| 层级不超过三级 | `/shops/1/dishes` | `/shops/1/categories/2/dishes/3` |
| 动词用 HTTP 方法表达 | `DELETE /cart/1` | `/deleteCart?id=1` |
| 状态变更用子资源 | `PATCH /orders/1/status` | `/updateOrderStatus` |
| 路径小写 + 连字符 | `/dish-categories` | `/dishCategories` |

### 1.3 统一响应结构

**成功响应**：

```json
{
  "code": 0,
  "message": "success",
  "data": { },
  "timestamp": 1728979200000,
  "traceId": "a1b2c3d4e5f6"
}
```

**失败响应**：

```json
{
  "code": 4003,
  "message": "菜品[宫保鸡丁]库存不足",
  "data": null,
  "timestamp": 1728979200000,
  "traceId": "a1b2c3d4e5f6"
}
```

**分页数据**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "records": [],
    "total": 128,
    "page": 1,
    "size": 10,
    "pages": 13
  },
  "timestamp": 1728979200000,
  "traceId": "a1b2c3d4e5f6"
}
```

### 1.4 HTTP 状态码使用

| 状态码 | 使用场景 |
| --- | --- |
| 200 | 业务处理成功（含业务失败但 HTTP 层成功，用 `code` 区分） |
| 400 | 请求参数格式错误、请求体无法解析 |
| 401 | 未登录或令牌无效 |
| 403 | 已登录但无权限 |
| 404 | 请求路径不存在 |
| 405 | HTTP 方法不支持 |
| 429 | 请求过于频繁 |
| 500 | 服务端内部错误 |

**约定**：业务规则失败（库存不足、状态非法等）统一返回 HTTP 200，通过 `code` 字段区分，避免前端对 HTTP 错误做过多的分支处理。

### 1.5 认证方式

除白名单接口外，所有接口需在请求头携带令牌：

```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**白名单接口**：

| 接口 | 说明 |
| --- | --- |
| `POST /auth/register` | 注册 |
| `POST /auth/login` | 登录 |
| `GET /captcha` | 图形验证码 |
| `GET /shops` | 店铺列表（游客可浏览） |
| `GET /shops/{id}` | 店铺详情 |
| `GET /shops/{id}/dishes` | 店铺菜品 |
| `GET /uploads/**` | 静态资源 |

### 1.6 错误码

| 区间 | 含义 |
| --- | --- |
| 0 | 成功 |
| 1000–1999 | 认证与账号 |
| 2000–2999 | 权限 |
| 3000–3999 | 参数校验 |
| 4000–4999 | 业务规则 |
| 5000–5999 | 系统与外部依赖 |

完整错误码见 [03-详细设计说明书 §2.3](03-详细设计说明书.md#23-错误码枚举)。

## 2 认证模块 `/auth`

### 2.1 用户注册

| 项 | 内容 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/auth/register` |
| 权限 | 公开 |
| 说明 | 注册普通用户账号 |

**请求体**：

```json
{
  "phone": "13800000001",
  "password": "Abc12345",
  "confirmPassword": "Abc12345",
  "nickname": "小鱼干",
  "role": "CONSUMER"
}
```

| 字段 | 类型 | 必填 | 校验规则 |
| --- | --- | --- | --- |
| `phone` | String | 是 | 11 位手机号 |
| `password` | String | 是 | 8–20 位，含字母与数字 |
| `confirmPassword` | String | 是 | 与 `password` 一致 |
| `nickname` | String | 否 | 2–20 字 |
| `role` | String | 是 | `CONSUMER` / `MERCHANT` / `RIDER` |

**响应**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "userId": 1001
  }
}
```

**错误**：

| code | 场景 |
| --- | --- |
| 1001 | 手机号已注册 |
| 3002 | 参数格式错误 |

## 6 订单模块 `/orders`

### 6.1 创建订单

| 项 | 内容 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/orders` |
| 权限 | CONSUMER |

**请求体**：

```json
{
  "shopId": 1,
  "addressId": 1,
  "items": [
    { "dishId": 101, "quantity": 2 },
    { "dishId": 102, "quantity": 1 }
  ],
  "remark": "少放辣"
}
```

> `items` 为空时表示结算购物车中该店铺的全部菜品。

**响应**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "orderId": 10001,
    "orderNo": "20261001120000123456",
    "totalAmount": "38.00",
    "status": 0,
    "statusDesc": "待支付",
    "expireAt": "2026-10-01 12:15:00"
  }
}
```

**错误**：

| code | 场景 |
| --- | --- |
| 4002 | 菜品已下架 |
| 4003 | 库存不足 |
| 4004 | 店铺已打烊 |
