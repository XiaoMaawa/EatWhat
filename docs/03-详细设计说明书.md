### 2.1 统一响应封装

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `Integer` | 业务状态码，0 表示成功 |
| `message` | `String` | 提示信息 |

```java
@Data
public class R<T> implements Serializable {
    private Integer code;
    private String message;
    private T data;
    private Long timestamp;
    private String traceId;

    public static <T> R<T> ok(T data) {
        R<T> r = new R<>();
        r.code = ErrorCode.SUCCESS.getCode();
        r.message = "success";
        r.data = data;
        r.timestamp = System.currentTimeMillis();
        r.traceId = MDC.get("traceId");
        return r;
    }

    public static <T> R<T> ok() {
        return ok(null);
    }

    public static <T> R<T> fail(ErrorCode errorCode) {
        return fail(errorCode.getCode(), errorCode.getMessage());
    }

    public static <T> R<T> fail(Integer code, String message) {
        R<T> r = new R<>();
        r.code = code;
        r.message = message;
        r.timestamp = System.currentTimeMillis();
        r.traceId = MDC.get("traceId");
        return r;
    }
}
```

### 2.5 全局异常处理器

**类**：`com.eatwhat.common.exception.GlobalExceptionHandler`

```java
@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BizException.class)
    public R<Void> handleBizException(BizException e) {
        log.warn("业务异常: code={}, msg={}", e.getCode(), e.getMessage());
        return R.fail(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public R<Void> handleValidException(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldErrors().stream()
            .map(FieldError::getDefaultMessage)
            .collect(Collectors.joining("; "));
        log.warn("参数校验失败: {}", msg);
        return R.fail(ErrorCode.PARAM_INVALID.getCode(), msg);
    }

    @ExceptionHandler(ConstraintViolationException.class)
    public R<Void> handleConstraintViolation(ConstraintViolationException e) {
        String msg = e.getConstraintViolations().stream()
            .map(ConstraintViolation::getMessage)
            .collect(Collectors.joining("; "));
        return R.fail(ErrorCode.PARAM_INVALID.getCode(), msg);
    }

    @ExceptionHandler(AccessDeniedException.class)
    public R<Void> handleAccessDenied(AccessDeniedException e) {
        log.warn("越权访问: {}", e.getMessage());
        return R.fail(ErrorCode.ACCESS_DENIED);
    }

    @ExceptionHandler(HttpMessageNotReadableException.class)
    public R<Void> handleBadBody(HttpMessageNotReadableException e) {
        return R.fail(ErrorCode.PARAM_INVALID.getCode(), "请求体格式错误");
    }

    @ExceptionHandler(DuplicateKeyException.class)
    public R<Void> handleDuplicateKey(DuplicateKeyException e) {
        log.warn("唯一键冲突: {}", e.getMessage());
        return R.fail(ErrorCode.PARAM_INVALID.getCode(), "数据已存在，请勿重复提交");
    }

    @ExceptionHandler(Exception.class)
    public R<Void> handleException(Exception e) {
        log.error("系统异常: ", e);
        return R.fail(ErrorCode.SYSTEM_ERROR);
    }
}
```

> **安全要点**：兜底分支绝不把 `e.getMessage()` 或堆栈返回给前端，避免泄露内部结构。

## 3 认证与授权详细设计

### 3.1 JWT 令牌结构

```json
// Header
{
  "alg": "HS256",
  "typ": "JWT"
}

// Payload
{
  "sub": "1001",
  "role": "CONSUMER",
  "iat": 1728979200,
  "exp": 1728986400,
  "jti": "a1b2c3d4-e5f6-7890"
}
```

| 声明 | 含义 | 是否可放敏感信息 |
| --- | --- | --- |
| `sub` | 用户 ID | 可 |
| `role` | 角色标识 | 可 |
| `iat` | 签发时间 | 可 |
| `exp` | 过期时间 | 可 |
| `jti` | 令牌唯一 ID，用于登出黑名单 | 可 |

**禁止**在载荷中放入手机号、身份证号、密码哈希等敏感信息，因为 JWT 载荷仅做 Base64 编码而非加密。

### 3.2 令牌签发与解析

**类**：`com.eatwhat.security.JwtTokenProvider`

```java
@Component
public class JwtTokenProvider {

    @Value("${eatwhat.jwt.secret}")
    private String secret;

    @Value("${eatwhat.jwt.expiration:7200000}")
    private long expiration;

    private SecretKey key() {
        return Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
    }

    public String generateToken(Long userId, String role) {
        Date now = new Date();
        return Jwts.builder()
            .subject(String.valueOf(userId))
            .claim("role", role)
            .id(UUID.randomUUID().toString())
            .issuedAt(now)
            .expiration(new Date(now.getTime() + expiration))
            .signWith(key())
            .compact();
    }

    public Claims parseToken(String token) {
        return Jwts.parser()
            .verifyWith(key())
            .build()
            .parseSignedClaims(token)
            .getPayload();
    }

    public boolean validate(String token) {
        try {
            parseToken(token);
            return true;
        } catch (JwtException | IllegalArgumentException e) {
            return false;
        }
    }
}
```

**密钥要求**：`eatwhat.jwt.secret` 至少 32 字节（HS256 要求 256 位），通过环境变量注入，禁止硬编码在代码或提交到仓库。

### 3.3 认证过滤器

**类**：`com.eatwhat.security.JwtAuthenticationFilter`

```java
@Component
@RequiredArgsConstructor
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JwtTokenProvider tokenProvider;

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain chain)
            throws ServletException, IOException {
        String token = resolveToken(request);
        if (StringUtils.hasText(token) && tokenProvider.validate(token)) {
            Claims claims = tokenProvider.parseToken(token);
            Long userId = Long.valueOf(claims.getSubject());
            String role = claims.get("role", String.class);

            List<GrantedAuthority> authorities =
                List.of(new SimpleGrantedAuthority("ROLE_" + role));
            AuthUser principal = new AuthUser(userId, role);
            UsernamePasswordAuthenticationToken auth =
                new UsernamePasswordAuthenticationToken(principal, null, authorities);
            auth.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));
            SecurityContextHolder.getContext().setAuthentication(auth);
        }
        chain.doFilter(request, response);
    }

    private String resolveToken(HttpServletRequest request) {
        String bearer = request.getHeader(HttpHeaders.AUTHORIZATION);
        if (StringUtils.hasText(bearer) && bearer.startsWith("Bearer ")) {
            return bearer.substring(7);
        }
        return null;
    }
}
```

```java
@Configuration
@EnableWebSecurity
@EnableMethodSecurity
@RequiredArgsConstructor
public class SecurityConfig {

    private final JwtAuthenticationFilter jwtFilter;
    private final AuthenticationEntryPoint authEntryPoint;
    private final AccessDeniedHandler accessDeniedHandler;

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf(AbstractHttpConfigurer::disable)
            .cors(cors -> cors.configurationSource(corsConfigurationSource()))
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers(
                    "/api/v1/auth/login",
                    "/api/v1/auth/register",
                    "/api/v1/captcha/**",
                    "/doc.html", "/webjars/**", "/v3/api-docs/**",
                    "/uploads/**"
                ).permitAll()
                .requestMatchers("/api/v1/admin/**").hasRole("ADMIN")
                .requestMatchers("/api/v1/merchant/**").hasAnyRole("MERCHANT", "ADMIN")
                .requestMatchers("/api/v1/rider/**").hasAnyRole("RIDER", "ADMIN")
                .anyRequest().authenticated()
            )
            .exceptionHandling(e -> e
                .authenticationEntryPoint(authEntryPoint)
                .accessDeniedHandler(accessDeniedHandler)
            )
            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class);

        return http.build();
    }

    @Bean
```

### 3.5 数据级权限校验

**问题**：接口级权限只能保证"角色对了"，无法保证"数据是自己的"。

**方案**：在 Service 层统一校验归属关系。

```java
private void checkShopOwnership(Long shopId, AuthUser current) {
    if (current.isAdmin()) {
        return;
    }
    Shop shop = shopMapper.selectById(shopId);
    if (shop == null || !shop.getMerchantId().equals(current.getUserId())) {
        throw new BizException(ErrorCode.DATA_NOT_OWNED);
    }
}
```

### 3.6 登录失败限制

使用 Caffeine 本地缓存实现失败计数：

```java
@Component
public class LoginAttemptService {

    private static final int MAX_ATTEMPTS = 5;
    private static final Duration LOCK_DURATION = Duration.ofMinutes(15);

    private final Cache<String, Integer> attempts = Caffeine.newBuilder()
        .expireAfterWrite(LOCK_DURATION)
        .maximumSize(10_000)
        .build();

    public void loginFailed(String account) {
        attempts.put(account, attempts.get(account, k -> 0) + 1);
    }

    public void loginSuccess(String account) {
        attempts.invalidate(account);
    }

    public boolean isBlocked(String account) {
        Integer count = attempts.getIfPresent(account);
        return count != null && count >= MAX_ATTEMPTS;
    }
}
```

### 4.2 创建订单核心实现

**DTO**：`com.eatwhat.modules.order.dto.CreateOrderDTO`

```java
@Data
```

**Service 实现**：

```java
@Slf4j
@Service
@RequiredArgsConstructor
public class OrderServiceImpl implements OrderService {

    private final OrderMapper orderMapper;
    private final OrderItemMapper orderItemMapper;
    private final OrderStatusLogMapper statusLogMapper;
    private final DishMapper dishMapper;
    private final ShopMapper shopMapper;
    private final UserAddressMapper addressMapper;
    private final CartItemMapper cartItemMapper;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public OrderVO createOrder(Long userId, CreateOrderDTO dto) {
        // 1. 校验店铺
        Shop shop = shopMapper.selectById(dto.getShopId());
        if (shop == null || !Integer.valueOf(1).equals(shop.getIsOpen())) {
            throw new BizException(ErrorCode.SHOP_CLOSED);
        }

        // 2. 校验地址归属
        UserAddress address = addressMapper.selectById(dto.getAddressId());
        if (address == null || !address.getUserId().equals(userId)) {
            throw new BizException(ErrorCode.DATA_NOT_OWNED);
        }

        // 3. 组装购买项
        List<CreateOrderDTO.OrderItemDTO> items = dto.getItems();
        if (CollectionUtils.isEmpty(items)) {
            items = cartItemMapper.selectByShop(userId, dto.getShopId())
                .stream()
                .map(c -> new CreateOrderDTO.OrderItemDTO(c.getDishId(), c.getQuantity()))
                .collect(Collectors.toList());
        }
        if (CollectionUtils.isEmpty(items)) {
            throw new BizException(ErrorCode.CART_EMPTY);
        }

        // 4. 逐项校验并计算金额
        List<OrderItem> orderItems = new ArrayList<>(items.size());
        BigDecimal goodsAmount = BigDecimal.ZERO;
        for (CreateOrderDTO.OrderItemDTO item : items) {
            Dish dish = dishMapper.selectById(item.getDishId());
            if (dish == null || !dish.getShopId().equals(dto.getShopId())) {
                throw new BizException(ErrorCode.DISH_NOT_FOUND);
            }
            if (!Integer.valueOf(1).equals(dish.getStatus())) {
                throw new BizException(ErrorCode.DISH_OFF_SALE,
                    "菜品[" + dish.getName() + "]已下架");
            }
            if (dish.getStock() < item.getQuantity()) {
                throw new BizException(ErrorCode.STOCK_NOT_ENOUGH,
                    "菜品[" + dish.getName() + "]库存不足");
            }
            BigDecimal subtotal = dish.getPrice()
                .multiply(BigDecimal.valueOf(item.getQuantity()));
            goodsAmount = goodsAmount.add(subtotal);

            OrderItem oi = new OrderItem();
            oi.setDishId(dish.getId());
            oi.setDishName(dish.getName());      // 快照
            oi.setDishImage(dish.getImage());    // 快照
            oi.setPrice(dish.getPrice());        // 快照
            oi.setQuantity(item.getQuantity());
            oi.setSubtotal(subtotal);
            orderItems.add(oi);
        }

        // 5. 校验起送价
        if (goodsAmount.compareTo(shop.getMinOrderAmount()) < 0) {
            throw new BizException(ErrorCode.BELOW_MIN_AMOUNT,
                "还差" + shop.getMinOrderAmount().subtract(goodsAmount) + "元起送");
        }

        // 6. 落库订单主表
        Order order = new Order();
        order.setOrderNo(generateOrderNo(userId));
        order.setUserId(userId);
        order.setShopId(shop.getId());
        order.setMerchantId(shop.getMerchantId());
        order.setStatus(OrderStatusEnum.PENDING_PAYMENT);
        order.setGoodsAmount(goodsAmount);
        order.setDeliveryFee(shop.getDeliveryFee());
        order.setTotalAmount(goodsAmount.add(shop.getDeliveryFee()));
        order.setReceiverName(address.getContactName());
        order.setReceiverPhone(address.getPhone());
        order.setReceiverAddress(address.getFullAddress());
        order.setRemark(dto.getRemark());
        orderMapper.insert(order);

        // 7. 落库明细
        for (OrderItem oi : orderItems) {
            oi.setOrderId(order.getId());
        }
        orderItemMapper.insertBatch(orderItems);

        // 8. 原子扣减库存
        for (OrderItem oi : orderItems) {
            int rows = dishMapper.deductStock(oi.getDishId(), oi.getQuantity());
            if (rows == 0) {
                throw new BizException(ErrorCode.STOCK_NOT_ENOUGH);
            }
        }

        // 9. 清空已结算购物车项
        cartItemMapper.deleteByUserAndShop(userId, shop.getId());

        // 10. 写入状态日志
        statusLogMapper.insert(OrderStatusLog.init(order.getId(), userId));

        log.info("订单创建成功: orderNo={}, userId={}, amount={}",
            order.getOrderNo(), userId, order.getTotalAmount());

        return OrderVO.from(order, orderItems);
    }

    private String generateOrderNo(Long userId) {
        return LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyyMMddHHmmss"))
            + String.format("%06d", ThreadLocalRandom.current().nextInt(1_000_000))
            + String.format("%02d", userId % 100);
```


### 6.2 距离计算

使用 Haversine 公式计算两点间球面距离：

```java
public final class GeoUtils {

    private static final double EARTH_RADIUS_KM = 6371.0;

    /** 计算两点间距离，单位：公里 */
    public static double distanceKm(double lat1, double lng1, double lat2, double lng2) {
        double dLat = Math.toRadians(lat2 - lat1);
        double dLng = Math.toRadians(lng2 - lng1);
        double a = Math.sin(dLat / 2) * Math.sin(dLat / 2)
                 + Math.cos(Math.toRadians(lat1)) * Math.cos(Math.toRadians(lat2))
                 * Math.sin(dLng / 2) * Math.sin(dLng / 2);
        double c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
        return EARTH_RADIUS_KM * c;
    }
}
```

**精度说明**：Haversine 假设地球为球体，在中小距离（< 100km）场景下误差小于 0.5%，满足外卖配送范围判定需求。

### 8.2 安全校验

```java
private static final Set<String> ALLOWED_EXT =
    Set.of("jpg", "jpeg", "png", "webp");
private static final Set<String> ALLOWED_MIME =
    Set.of("image/jpeg", "image/png", "image/webp");

public String upload(MultipartFile file) {
    if (file.isEmpty()) {
        throw new BizException(ErrorCode.UPLOAD_FAILED, "文件为空");
    }
    if (file.getSize() > 5 * 1024 * 1024) {
        throw new BizException(ErrorCode.FILE_SIZE_EXCEEDED);
    }

    String original = file.getOriginalFilename();
    String ext = StringUtils.getFilenameExtension(original);
    if (ext == null || !ALLOWED_EXT.contains(ext.toLowerCase())) {
        throw new BizException(ErrorCode.FILE_TYPE_NOT_ALLOWED);
    }
    if (!ALLOWED_MIME.contains(file.getContentType())) {
        throw new BizException(ErrorCode.FILE_TYPE_NOT_ALLOWED);
    }

    // 校验文件头魔数，防止改扩展名绕过
    if (!ImageValidator.isRealImage(file)) {
        throw new BizException(ErrorCode.FILE_TYPE_NOT_ALLOWED);
    }

    String datePath = LocalDate.now().format(DateTimeFormatter.ofPattern("yyyy/MM/dd"));
    String filename = UUID.randomUUID().toString().replace("-", "") + "." + ext;
    Path target = Paths.get(uploadPath, datePath, filename).normalize();

    // 防止路径穿越
    if (!target.startsWith(Paths.get(uploadPath).normalize())) {
        throw new BizException(ErrorCode.FILE_TYPE_NOT_ALLOWED);
    }

    Files.createDirectories(target.getParent());
    file.transferTo(target.toFile());
    return "/uploads/" + datePath + "/" + filename;
}
```

```javascript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import { login as loginApi, logout as logoutApi } from '@/api/auth'

export const useUserStore = defineStore('user', () => {
  const token = ref(localStorage.getItem('token') || '')
  const userInfo = ref(JSON.parse(localStorage.getItem('userInfo') || 'null'))

  const role = computed(() => userInfo.value?.role || '')
  const isLogin = computed(() => !!token.value)

  async function login(form) {
    const data = await loginApi(form)
    token.value = data.token
    userInfo.value = data.userInfo
    localStorage.setItem('token', data.token)
    localStorage.setItem('userInfo', JSON.stringify(data.userInfo))
  }

  async function logout() {
    try { await logoutApi() } catch (e) { /* 忽略登出接口异常 */ }
    token.value = ''
    userInfo.value = null
    localStorage.removeItem('token')
    localStorage.removeItem('userInfo')
  }

  return { token, userInfo, role, isLogin, login, logout }
})
```
